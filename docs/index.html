Открытый почтовый клиент и админ-панель поверх обычных IMAP и SMTP. Писем у себя не хранит, внешних сервисов не требует, ставится за вечер. Веб-интерфейс работает уже сейчас, нативные приложения для Windows, macOS, Linux, Android и iOS — в разработке. Лицензия MIT.

Смотреть на GitHub Как поставить

Что это

Один процесс на Python: интерфейс почты, админ-панель и мост к вашему почтовому серверу.

Ваши письма остаются вашими

Приложение не хранит почту — оно показывает то, что лежит на вашем IMAP. Убрали приложение, почта осталась на месте.

Работает с любым сервером

Dovecot, Postfix, корпоративный сервер, ящик у провайдера. Внешний ящик подключается по своему IMAP-хосту рядом с основным.

Админ-панель в комплекте

Ящики и алиасы, многодоменный каталог сотрудников, синхронизация с LDAP и Active Directory.

Вход, какой удобен

Пароль почтового ящика или внешний OIDC-провайдер, привязка Telegram.

Ничего лишнего в зависимостях

FastAPI, uvicorn и SQLite для служебного состояния. Фронтенд — обычные HTML, CSS и JS, сборки нет.

MIT без оговорок

Берите, меняйте, ставьте клиентам, стройте на этом сервис. Просить разрешения не нужно.

Поставить за пару команд

Нужен Python 3.11 или новее. Обратный прокси — nginx или Caddy — терминирует TLS.

# исходники и зависимости
git clone https://github.com/lmcorp-it/RuPochta.git && cd RuPochta
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# свой почтовый контур
export MAIL_DOMAIN=example.com MAIL_HOST=imap.example.com
export MAIL_ADMIN_KEY=... WEBMAIL_SECRET_KEY=...

# запуск
.venv/bin/python -m uvicorn rupochta_server:app --host 127.0.0.1 --port 18400

То же самое в Docker: docker build -t rupochta . и docker run -p 18400:18400 -v rupochta-data:/data rupochta. Полный список переменных — в README.
